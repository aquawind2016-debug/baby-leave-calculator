👶 2026년 출산·육아휴직 통합 계산기

2026년 최신 개정 정책(상한액 인상, 1년 6개월 연장, 25% 사후지급금 폐지 등)을 완벽하게 반영한 출산 및 육아휴직 계산기 웹 애플리케이션입니다.

🌟 주요 기능

출산휴가 기간 계산

엄마(출산전후휴가): 일반(90일) 및 다태아(120일) 적용 계산

아빠(배우자 출산휴가): 2025년 개정된 20일 기준 적용 계산

육아휴직 기간 연장 확인

부모 동시/순차 3개월 이상 사용, 한부모, 중증 장애 아동 등 1년 6개월(18개월) 연장 조건 판별

육아휴직 급여 모의계산

사후지급금 폐지 반영: 휴가 기간 중 100% 전액 지급(2025.01 시행)

일반 육아휴직: 1~3개월(250만 원), 4~6개월(200만 원), 7개월 이후(160만 원)

6+6 부모 육아휴직제: 1~6개월 차 상한액 단계별 인상 (최대 450만 원) 반영

한부모 육아휴직 특례: 1~3개월 차 상한액 300만 원 적용

🛠 기술 스택

HTML5

JavaScript (Vanilla)

Tailwind CSS (CDN) - 모바일 및 PC 반응형 UI 구현
